## 0. 总览

- 定位：面向短视频批量处理的桌面工具，底层调用 FFmpeg。
- 两类能力：
  1. **批量流水线**（原“操作面板”）：对队列里每个视频套用同一组参数，一次编码输出。
  2. **独立工具**（原“队列右键 → 独立功能”）：单一用途的批处理，只沿用流水线里的“码率”和“输出位置”。
- 通用约定：
  - **范围值**：大多数数值参数是 `[最小, 最大]`，每个视频（每次裂变）在范围内随机取值；两端相等即固定值。
  - **素材来源**：水印、背景、片头尾、音乐等均支持“单文件”或“目录（随机/依次取）”两种模式。
  - **即时预览**：多数模块可对单个视频预览效果；另有“生成预览”预览整条流水线的最终效果。
  - **硬件加速**：默认启用 GPU 编码（Intel QSV / NVIDIA NVENC / AMD AMF），失败可回退软件编码。

## 1. 任务队列与导入

| ID | 功能 | 说明 | 状态 |
|---|---|---|---|
| `queue.import` | 导入 | 选文件、选文件夹、拖放（文件与文件夹混拖）；可选是否递归子目录；超过 10 个显示导入进度 | ✅ |
| `queue.probe` | 媒体信息 | 导入后读取分辨率、时长、帧率、码率、编码、音轨/字幕轨；显示 CC（有字幕）、FC（有封面）标记 | ✅ |
| `queue.sidecar` | 同名资源自动加载 | 同目录同名字幕文件、同名图片（作封面）可自动关联（设置 `set.auto-subtitle` / `set.auto-cover`）；队列行显示 CC / FC 标记，右键“字幕与封面”可手动设置 / 清除、“全部重载”；处理时字幕烧录进画面（`set.auto-subtitle` 的样式）、封面嵌入输出，预览同样显示字幕（双击播放源视频时不叠加字幕） | ✅ |
| `queue.manage` | 队列操作 | 全选/反选、删除、清空、插队、排序、查看媒体信息、双击预览播放（可带字幕；字幕显示随 `queue.sidecar` 实现） | ✅ |
| `queue.run` | 执行 | 开始/停止；并行任务数可设；每条任务显示进度与状态；处理记录（日志）面板；状态栏汇总 | ✅ |
| `queue.persist` | 未完成任务恢复 | 退出时保存未完成队列，下次启动自动载入（队列变化时即保存；已不存在的文件丢弃并记入处理记录，缺少的媒体信息重新探测） | ✅ |

## 2. 批量流水线模块

每个模块可独立开关，参数随“配方”一起保存。

### 2.1 叠加类

| ID | 功能 | 参数要点 | FFmpeg 思路 | 状态 |
|---|---|---|---|---|
| `pipe.remove-watermark` | 去水印（区域模糊） | 预设方案（各平台常见水印位置）或自定义 1～2 处矩形；可限定生效时段；预览时用框线标出区域 | `delogo` / 裁出区域 `boxblur` 后 `overlay`，`enable='between(t,a,b)'` |✅ |
| `pipe.add-watermark` | 加水印 | 图片 / GIF / 视频（mp4、mov）；位置（九宫格 + 边距偏移）、大小、透明度、滚动效果；居中时可拉伸；倒序播放；去除水印素材的背景色；目录模式下可随机取、分段依次显示；支持第二个“子水印”（参数较少） | `overlay` + `colorkey`/`chromakey` + `format=rgba,colorchannelmixer=aa=` |✅ |
| `pipe.pip` | 画中画 | 两种模式：①自身画面作背景；②外部图片/视频作背景（单文件或目录随机）。可设边距、相对居中的偏移、视频位置自定义、背景虚化及强度、前景纯色抠除（绿幕） | `split` → 背景 `scale,boxblur` → `overlay`；抠像 `chromakey` |✅ |
| `pipe.text` | 文本 | 最多 3 处；内容来源：文件名（可设断行符、截掉不需要的子串）、文本目录、自定义文本；字体/颜色/描边等样式、分行、延时显示 | `drawtext`（或生成 ASS 后 `subtitles`） |✅ |

### 2.2 画面类

| ID | 功能 | 参数要点 | FFmpeg 思路 | 状态 |
|---|---|---|---|---|
| `pipe.crop` | 裁剪 | 指定四边/手动框选；按百分比裁切；四边随机裁剪；“居中 + 比例”（如 4:3）模式 | `crop` |✅ |
| `pipe.resolution` | 分辨率 | 标准档位（统一高度，宽度等比）或自定义宽高；自定义时可选缩放模式：拉伸 / 原比例；原比例下空白可用背景（可虚化）或黑色填充，不用背景时可加倒影效果 | `scale` + `pad` / 背景 `overlay`；倒影 `vflip` + 渐隐 |✅ |
| `pipe.rotate-flip` | 旋转与翻转 | 90°/180°/270°、水平/垂直翻转；随机任意角度旋转，可选“完全显示”或“去除黑边”（二选一） | `transpose` / `hflip` / `vflip` / `rotate` + `crop` |✅ |
| `pipe.adjust` | 画面调整 | 亮度、对比度、饱和度、锐化、降噪（均为范围值）；LUT 滤镜；更多效果：入场效果、光晕、黑白、渐出、边框（颜色可随机）、开幕动画、马赛克、蒙板倒置（原画面半透明倒置后叠加） | `eq` / `unsharp` / `hqdn3d` / `lut3d` / `fade` / `vignette` / `drawbox` / `blend` |✅ |
| `pipe.grid` | 宫格分屏 | 把同一画面按 2/3/4/9… 宫格重复排布；方向自动（2、3 宫格时横屏则竖排、竖屏则横排）；可选两端虚化 | `split` + `hstack`/`vstack`/`xstack` |✅ |
| `pipe.zoom` | 动态缩放 | 在指定范围内对画面做放大/缩小的往复变化，有独立参数（幅度、周期等） | `zoompan` 或 `scale` 表达式 + `crop` |✅ |

### 2.3 时间类

| ID | 功能 | 参数要点 | FFmpeg 思路 | 状态 |
|---|---|---|---|---|
| `pipe.trim` | 去头尾 | 按时长去片头/片尾，或“起点 + 长度”截取；均为范围值；可设最短时长下限（截取后不短于该值） | `-ss` / `-to` / `trim` |✅ |

| `pipe.dedupe-frames` | 重复帧移除 | 去掉连续重复帧 | `mpdecimate` + `setpts` |✅ |

## 4. 设置

### 4.1 转换

| ID | 设置 | 说明 | 状态 |

### 4.3 高级开关（原 options.ini）

| ID | 设置 | 说明 | 状态 |
|---|---|---|---|
| `set.fission-folder` | 裂变独立文件夹 | 每次裂变输出到“第 x 次裂变”目录 | ✅ |

## 5. 开源版与原软件的差异

| 项 | 原软件 | 开源版 |
|---|---|---|
| 注册 / 购买 / 设备绑定 | 有 | **不做**，开源免费（MIT） |
| 语音生成字幕 | 外部 VideoSrt + 阿里云 | 已实现为本地 whisper.cpp（FFmpeg whisper 滤镜或 whisper-cli），模型由用户自备，不用云端 |
| 字幕擦除 | 阿里云服务 | 已实现为本地近似处理（delogo / 模糊 / 纯色遮盖），不用云服务、不自动识别字幕位置 |
| 自动更新 | 自建增量包 | 已实现：查询 GitHub Releases 最新版本并提示打开发布页；不做自动下载替换（如需可再评估 Tauri updater） |
| FFmpeg | 随安装包分发 | 不入库、不分发：使用系统 PATH 中的 FFmpeg 或环境变量 `CLIPRECIPE_FFMPEG`；设置 → 关于 显示检测结果（注意 FFmpeg 的 LGPL/GPL 条款） |
| 平台 | 仅 Windows | Windows 优先，代码保持跨平台 |
| `tool.change-duration`、`tool.freeze-play` 的“暂停图标” | 用于让平台或观众产生误判 | 已实现（见第 3 节说明）；是否保留在开源版中由维护者决定 |

## 6. 建议的实现顺序

1. **基础**：FFmpeg 定位与探测、`queue.import` / `queue.probe`、任务调度与进度解析、`pipe.output`、设置持久化。
2. **流水线骨架**：参数模型（范围值、素材来源）→ 滤镜图生成器 → 先接入 `pipe.fps`、`pipe.bitrate`、`pipe.crop`、`pipe.resolution`、`pipe.rotate-flip`、`pipe.trim`。
3. **预览**：单模块预览与 `pipe.preview`。
4. **其余流水线模块**、`pipe.fission`、`pipe.recipe`。
5. **独立工具**：先做纯 FFmpeg 一步可达的（`tool.remux`、`tool.extract-av`、`tool.gif`、`tool.merge`、`tool.split`…），再做依赖场景检测的重组类，最后是字幕类。
