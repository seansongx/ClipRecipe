# 批量流水线模块

每个模块可独立开关，参数随“配方”一起保存。配方栏只列已启用和本次会话里动过的步骤，每行显示当前取值摘要，点击展开参数；其它步骤经“添加步骤”菜单加入。

## 叠加类

| ID | 功能 | 参数要点 | FFmpeg 思路 |
|---|---|---|---|
| `pipe.remove-watermark` | 去水印（区域模糊） | 预设方案（各平台常见水印位置）或自定义 1～2 处矩形；可限定生效时段；预览时用框线标出区域 | `delogo` / 裁出区域 `boxblur` 后 `overlay`，`enable='between(t,a,b)'` |
| `pipe.add-watermark` | 加水印 | 图片 / GIF / 视频（mp4、mov）；位置（九宫格 + 边距偏移；也可以在预览舞台的效果画面上直接拖动主水印，或聚焦后按方向键微调，松手后换算成位置与固定边距，靠近中线时吸附到居中；滚动、拉伸铺满、分段依次显示时不能拖）、大小、透明度、滚动效果；居中时可拉伸；倒序播放；去除水印素材的背景色；目录模式下可随机取、分段依次显示；支持第二个“子水印”（参数较少） | `overlay` + `colorkey`/`chromakey` + `format=rgba,colorchannelmixer=aa=` |
| `pipe.pip` | 画中画 | 两种模式：①自身画面作背景；②外部图片/视频作背景（单文件或目录随机）。可设边距、相对居中的偏移、视频位置自定义、背景虚化及强度、前景纯色抠除（绿幕） | `split` → 背景 `scale,boxblur` → `overlay`；抠像 `chromakey` |
| `pipe.text` | 文本 | 最多 3 处；内容来源：文件名（可设断行符、截掉不需要的子串）、文本目录、自定义文本；字体/颜色/描边等样式、分行、延时显示 | `drawtext`（或生成 ASS 后 `subtitles`） |

## 画面类

| ID | 功能 | 参数要点 | FFmpeg 思路 |
|---|---|---|---|
| `pipe.crop` | 裁剪 | 指定四边/手动框选；按百分比裁切；四边随机裁剪；“居中 + 比例”（如 4:3）模式 | `crop` |
| `pipe.resolution` | 分辨率 | 标准档位（统一高度，宽度等比）或自定义宽高；自定义时可选缩放模式：拉伸 / 原比例；原比例下空白可用背景（可虚化）或黑色填充，不用背景时可加倒影效果 | `scale` + `pad` / 背景 `overlay`；倒影 `vflip` + 渐隐 |
| `pipe.rotate-flip` | 旋转与翻转 | 90°/180°/270°、水平/垂直翻转；随机任意角度旋转，可选“完全显示”或“去除黑边”（二选一） | `transpose` / `hflip` / `vflip` / `rotate` + `crop` |
| `pipe.adjust` | 画面调整 | 亮度、对比度、饱和度、锐化、降噪（均为范围值）；LUT 滤镜；更多效果：入场效果、光晕、黑白、渐出、边框（颜色可随机）、开幕动画、马赛克、蒙板倒置（原画面半透明倒置后叠加） | `eq` / `unsharp` / `hqdn3d` / `lut3d` / `fade` / `vignette` / `drawbox` / `blend` |
| `pipe.grid` | 宫格分屏 | 把同一画面按 2/3/4/9… 宫格重复排布；方向自动（2、3 宫格时横屏则竖排、竖屏则横排）；可选两端虚化 | `split` + `hstack`/`vstack`/`xstack` |
| `pipe.zoom` | 动态缩放 | 在指定范围内对画面做放大/缩小的往复变化，有独立参数（幅度、周期等） | `zoompan` 或 `scale` 表达式 + `crop` |

## 时间类

| ID | 功能 | 参数要点 | FFmpeg 思路 |
|---|---|---|---|
| `pipe.trim` | 去头尾 | 按时长去片头/片尾，或“起点 + 长度”截取；均为范围值；可设最短时长下限（截取后不短于该值） | `-ss` / `-to` / `trim` |
| `pipe.intro-outro` | 加头尾与边框 | 片头、片尾视频；相框图片及其与画面的间距 | `concat` 滤镜；相框 `overlay` |
| `pipe.speed` | 变速 | 固定倍率或分段变速（分段可随机组合，不支持预览）；可设最短时长避免过短；是否同时变调 | `setpts` + `atempo`（不变调）/ `asetrate`（变调） |
| `pipe.drop-frames` | 抽帧 | 每隔 N 帧丢 1 帧（范围值）；默认同步加速音频，可关闭；会缩短时长 | `select='mod(n,N)'` + `setpts` + `atempo` |
| `pipe.dedupe-frames` | 重复帧移除 | 去掉连续重复帧 | `mpdecimate` + `setpts` |

## 音频类

| ID | 功能 | 参数要点 | FFmpeg 思路 |
|---|---|---|---|
| `pipe.bgm` | 背景音 | 单文件或目录（mp3/m4a，可随机分配）；音量、原声音量、循环、延迟、淡入淡出；不支持即时预览 | `amix` + `volume` + `afade` + `adelay` + `-stream_loop` |

## 编码类

| ID | 功能 | 参数要点 |
|---|---|---|
| `pipe.fps` | 帧率 | 范围值；重置参数后默认仅启用此项 |
| `pipe.bitrate` | 码率 | 不启用则沿用源码率；倍率模式（<1 压缩，>1 提升）或固定值（可手输） |

## 流水线级功能

| ID | 功能 | 说明 |
|---|---|---|
| `pipe.fission` | 裂变次数 | 同一视频按随机参数生成 N 个不同输出；N>1 时输出到以视频名命名的文件夹；可选每次裂变放入独立的“第 x 次”文件夹 |
| `pipe.preview` | 生成预览 | 预览整条流水线的最终效果（变速、背景音、片头尾、帧率、码率除外）。中栏预览舞台常驻显示当前视频套用当前配方后的一帧，参数变化后自动刷新（批量处理中暂停），可切换原片 / 效果、拖动取帧时间；裂变次数大于 1 时列出最多 3 个不同随机值的变体，可“换一组随机值”；舞台的“生成预览”按钮播放整条流水线的低清片段 |
| `pipe.reset` | 参数重置 | 配方栏“更多”菜单里的“重置…”，二次确认后恢复默认值 |
| `pipe.output` | 输出位置 | 选择/粘贴/拖入文件夹；输出目录与源目录相同时给出警告；与“开始处理 / 停止”一起在配方栏底部，并显示“N 个视频 → M 个输出” |
| `pipe.recipe` | 配方导入导出 | 配方栏标题处的导入 / 导出图标按钮：把当前全部参数存为文件、再导入；支持把配方文件拖入窗口加载（原“参数”菜单）。“更多”菜单里另有“查看命令” |
