# 任务队列与导入

| ID | 功能 | 说明 |
|---|---|---|
| `queue.import` | 导入 | 选文件、选文件夹、拖放（文件与文件夹混拖）；可选是否递归子目录；超过 10 个显示导入进度 |
| `queue.probe` | 媒体信息 | 导入后读取分辨率、时长、帧率、码率、编码、音轨/字幕轨；显示 CC（有字幕）、FC（有封面）标记 |
| `queue.sidecar` | 同名资源自动加载 | 同目录同名字幕文件、同名图片（作封面）可自动关联（设置 `set.auto-subtitle` / `set.auto-cover`）；队列行显示 CC / FC 标记，右键“字幕与封面”可手动设置 / 清除、“全部重载”；处理时字幕烧录进画面（`set.auto-subtitle` 的样式）、封面嵌入输出，预览同样显示字幕（双击播放源视频时不叠加字幕） |
| `queue.manage` | 队列操作 | 标题旁显示视频数与总时长；“添加”菜单（添加视频 / 添加文件夹）；“更多”菜单里全选 / 反选 / 排序 / 清空；按状态筛选（全部 / 待处理 / 完成 / 失败，筛选时不能拖动排序）；选中后列表下方出现操作条（置顶插队、上移、下移、工具、移除）；查看媒体信息、双击预览播放（可带字幕；字幕显示随 `queue.sidecar` 实现）。行内状态显示为短状态，轮次、速度、输出数等细节在下一行 |
| `queue.run` | 执行 | 开始/停止；并行任务数可设；每条任务显示进度与状态；处理记录（日志）面板；状态栏汇总。处理记录可“复制记录”：复制全部记录，开头带环境信息，总是包含 FFmpeg 命令行（不管是否勾选“显示命令行”）。失败的任务（批量处理与独立工具）在错误信息下有“复制错误信息”（环境信息、文件名、错误、这条任务的处理记录）与“反馈问题”（打开预填了环境信息与错误信息的新建 issue 页面，错误信息过长时截短）。复制与预填的内容会把路径里的系统用户名换成 `***` |
| `queue.persist` | 未完成任务恢复 | 退出时保存未完成队列，下次启动自动载入（队列变化时即保存；已不存在的文件丢弃并记入处理记录，缺少的媒体信息重新探测） |
