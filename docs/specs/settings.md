# 设置

## 转换

| ID | 设置 | 说明 |
|---|---|---|
| `set.format` | 目标格式 | MP4（默认）或保持源格式 |
| `set.exists` | 目标已存在时 | 重命名（默认）或覆盖 |
| `set.name-strip` | 文件名去除 | 从输出文件名中去掉指定字符串，可用正则 |
| `set.parallel` | 并行任务数 | 上限为 CPU 核心数 |
| `set.auto-subtitle` | 自动加载同名字幕 | 加载后烧录进画面；“字幕样式”（字体、字号、颜色、描边、底部边距，以 1080 高为基准）作用于 srt / vtt，ass / ssa 保留自带样式 |
| `set.auto-cover` | 自动加载同名封面 | 封面嵌入帧数（默认 1 帧；不超过帧率时盖住开头 N 帧，大于帧率时改为“图片生成视频再合并”）；是否拉伸至视频尺寸；mp4 / mov 另写入封面图（attached_pic） |
| `set.hevc` | 使用 H.265 | 默认 H.264；开启时提示兼容性风险 |
| `set.hdr` | HDR 转 SDR | 按 ffprobe 色彩信息识别 HDR（PQ / HLG）并色调映射为 BT.709；或保留 HDR：10 bit H.265 + 原色彩信息（选了 H.264 时提示并改用 H.265） |
| `set.blur-center` | 虚化背景取画面中间 | 影响画中画、分辨率的虚化背景：取中间区域拉伸 / 整幅拉伸。模块参数 `blurCenter` 为空（新配方默认）时跟随本设置，旧配方里的 true / false 仍优先 |
| `set.skip-done` | 重新处理时跳过已完成 | 改过参数想重跑时关闭 |

## 通用

| ID | 设置 | 说明 |
|---|---|---|
| `set.after-all` | 全部完成后 | 无操作 / 关机（30 秒倒计时可取消，仅单次有效）/ 退出程序 |
| `set.open-output` | 完成后打开输出文件夹 | |
| `set.sound` | 完成提示音 | 可用自定义 wav；默认内置提示音（WebAudio 合成） |
| `set.gpu` | GPU 硬件加速 | 默认开；可设核显优先；装了驱动但试编码失败时提示（可关闭提示） |
| `set.number-prefix` | 文件名加队列序号 | |
| `set.recursive` | 目录模式包含子目录 | 同时作用于素材目录与视频导入（素材目录：新建时的初始值，之后以素材自己的勾选为准） |
| `set.out-by-folder` | 输出到来源文件夹同名目录 | 文件夹方式导入时保持分类结构 |
| `set.out-by-name` | 输出到视频同名文件夹 | 裂变次数 >1 时总是如此 |
| `set.delete-source` | 处理后删除源视频 | 开启需二次确认；默认移入回收站，可改为永久删除；只在输出写完并校验后执行 |
| `set.move-back` | 输出移回源位置 | 按“目标已存在时”的规则替换或重命名（不会覆盖源视频本身） |
| `set.remove-task` | 完成后从队列移除 | 删除任务时可弹确认 |
| `set.keep-queue` | 保留未完成任务列表 | |
| `set.auto-update` | 启动时检查更新 | 另有手动检查入口；读 GitHub Release 的 latest.json，发现新版本时显示版本号与说明，确认后下载（可取消）、校验签名、安装并重启；deb 安装、开发版、未配置公钥的构建或下载失败时改为打开发布页 |
| `set.tray` | 关闭窗口时最小化到托盘 | 托盘菜单：显示主窗口 / 退出 |
| `set.mute-preview` | 静音预览 | |
| `set.theme` | 主题 | 浅色 / 深色 / 跟随系统；导航栏按钮快速切换 |

## 高级开关（原 options.ini）

| ID | 设置 | 说明 |
|---|---|---|
| `set.fission-folder` | 裂变独立文件夹 | 每次裂变输出到“第 x 次裂变”目录 |
| `set.speed-fit` | 变速适应 | 独立工具中的变速适应时长：音视频合成把视频变速到配对音频的时长（重编码视频，保留的原声同步变速）；截取合并在有目标时长（目标模式或“截去超出长度”）时把每个输出变速到目标时长，代替截断。倍数限 0.25～4，超出时按原方式处理并提示。其它工具没有“目标时长”，不受影响 |
| `set.reduce-size` | 体积压缩 | 文件“瘦身”：恒定质量 CRF 28（H.265 为 32）+ slow 预设，以源码率为上限；启用码率模块时以模块为准 |
| `set.copyright` | 版权信息 | 写入输出视频元数据：批量处理，以及独立工具输出的视频文件（框架统一写入，重编码与直接复制都有效；图片、GIF、HLS 不写） |

## 其它入口

- 打开数据目录（配置、保存的队列）：设置 → 关于。
- 使用文档（GitHub 仓库 README）、关于（版本、MIT 许可、FFmpeg 说明）：设置 → 关于。
