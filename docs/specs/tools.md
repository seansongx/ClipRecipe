# 独立工具

## 合并与分割

| ID | 功能 | 说明 |
|---|---|---|
| `tool.merge` | 视频合并 | 合并全部/选中/自定义规则；无损合并或重编码；重编码时可加转场；可在视频之间插入“中间视频”（来自目录）；输出名可用各文件名以空格连接 |
| `tool.split` | 视频分割 | 按时长/段数分割；无损或重编码（默认推荐重编码，避免关键帧导致时间不准）；按场景切换点分割 |
| `tool.folder-merge` | 文件夹合并 | 与自定义合并相同的规则，素材来自指定文件夹及子文件夹 |
| `tool.clip-merge` | 截取合并 | 从文件夹（含子文件夹）中的每个视频截取符合条件的片段后拼成一个；可“截去超出长度”（启用后中间视频、片头尾不可用） |
| `tool.hls` | M3U8 切片 | 批量切为 HLS；无损切片，分片时长会有误差 |

## 重组

| ID | 功能 | 说明 |
|---|---|---|
| `tool.mirror-remix` | 镜像重组 | 按场景分割 → 部分片段水平翻转 → 重新拼接 |
| `tool.transition-remix` | 转场重组 | 按场景分割 → 片段间加转场 → 重新拼接 |
| `tool.split-remix` | 拆分重组 | 在设定位置拆开，中间插入一段视频后拼接 |
| `tool.remove-remix` | 移除重组 | 在设定位置移除指定长度后拼接 |
| `tool.simple-mix` | 简单混剪 | 主视频 + 副视频片段（铺满或居中叠加）+ 背景音频 + 字幕文件 |

## 画面效果

| ID | 功能 | 说明 |
|---|---|---|
| `tool.freeze-anim` | 定帧动画 | 按定帧数量或定格间隔，让画面停在指定位置的帧上 |
| `tool.freeze-play` | 定格播放 | 在指定位置暂停指定时长，可叠加暂停图标 |
| `tool.camera-move` | 运镜效果 | 按分辨率与时长裁取画面中间区域做往复平移，可预览 |
| `tool.remove-black-bars` | 黑边去除 | 自动检测并裁掉黑边（`cropdetect` → `crop`） |
| `tool.insert-frame` | 插帧 | 在指定位置插入图片并显示指定帧数 |
| `tool.progress-bar` | 进度条 | 在画面上绘制播放进度条；可用配置文件定义分段文字，可用动图作进度指示 |
| `tool.orientation` | 横竖互转 | 对文件夹内视频批量横竖屏转换，空白处填充纯色或图片 |
| `tool.stitch` | 画面拼接 | 把文件夹下多个视频拼成分屏；可“依次播放”（上一个播完下一个才开始）；四屏时可“依次填充播放” |
| `tool.reverse` | 视频倒放 | 可同时去除音频；长视频内存占用高，需分段处理或给出提示 |
| `tool.image-to-video` | 图转视频 | 文件夹内图片批量转同名 mp4；可设分辨率、帧率、时长、入场动画 |
| `tool.gif` | 生成 GIF | 批量转 GIF；高质量模式（调色板，慢且体积大） |
| `tool.screenshots` | 批量截图 | 按设置批量截图；可把文件名（去扩展名）绘入图片，字号、颜色、描边、位置在本工具中设置（封面处理不绘制文字，没有可沿用的样式） |

## 时间与静止

| ID | 功能 | 说明 |
|---|---|---|
| `tool.remove-still` | 静止帧移除 | 移除画面静止的片段（`freezedetect`） |
| `tool.remove-silence` | 静音移除 | 检测静音片段后移除或加速（`silencedetect`），拆分再合成 |
| `tool.smart-trim` | 智能去头尾 | 依据场景切换点判断片头片尾并去除 |
| `tool.change-duration` | 改变视频时长 | 只修改容器里的时长元数据，实际播放内容不变（MP4 / MOV 的 mvhd；FFmpeg 系读取方仍显示真实时长） |

## 音频、提取与转换

| ID | 功能 | 说明 |
|---|---|---|
| `tool.extract-av` | 音视频提取 | 提取音频或纯视频；多音轨可全部导出；mp3 可选码率 |
| `tool.av-mux` | 音视频合成 | 音频文件夹 + 视频文件夹批量配对合成，可保留原视频声音 |
| `tool.volume-pitch` | 音量音调 | 批量调整音量、音调，可统一响度 |
| `tool.remux` | 无损转换 | 仅换封装（mp4 ↔ mkv 等），不重编码 |

## 字幕与封面

| ID | 功能 | 说明 |
|---|---|---|
| `tool.subtitle-asr` | 语音生成字幕 | 本地 whisper.cpp 识别（FFmpeg 内置 whisper 滤镜或外部 whisper-cli，模型由用户自备，不用云端）生成 SRT，可放输出位置或源视频旁；可选烧录进新视频，字幕样式可自定义 |
| `tool.subtitle-extract` | 字幕提取 | 导出 mkv/mp4 内嵌字幕轨（有内嵌字幕时可用） |
| `tool.subtitle-erase` | 字幕擦除 | 本地近似处理（不用云服务）：在底部字幕条或框选区域用 delogo 修补 / 模糊 / 纯色遮盖，可限定时段；不自动识别字幕位置 |
| `tool.cover` | 封面处理 | 指定图片作封面嵌入视频；从视频指定位置截取封面并关联；可设截图文件名样式 |
